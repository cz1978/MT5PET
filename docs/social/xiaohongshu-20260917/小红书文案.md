我给MT5养了个会提醒的桌宠

# 正文（可直接复制）

最近给自己做了一个交易桌宠：天禄 TradePet。

平时待在桌面角落，点开能看持仓、风险和交易计划。会动的小家伙，加上一套认真做的交易记录工具，还挺有陪伴感 🌱

做它时最想解决的，是交易里那些很容易被忘掉的小事：
止损有没有设？今天开仓是不是太频繁？平仓时想着“晚点复盘”，后来还记得当时怎么想的吗？

目前做了这几个功能👇

🐾 桌宠 + 持仓快览
浮动卡片看实时盈亏，桌宠大小、透明度、鼠标穿透都能调。

📍 亏损区域记忆
把历史亏损交易整理成价格区域。再次接近时，提醒你回头看看：之前在这里发生过什么。

🔔 风险与纪律提醒
缺失止损、开仓次数、利润回吐、重要宏观数据，都有对应提醒。

📝 逐笔复盘 + 每日报告
记录进出场想法、行为标签，也能回放真实行情。每天整理报告，保存成 Markdown，或者复制给 AI 继续分析。

它只读连接 MT5，不下单、不平仓、不改单，交易数据默认留在本机。

现在支持 Windows 10/11 x64 + MT5。完整逐笔复盘主要面向对冲账户，个人项目还在持续打磨中。

我给它的定位就是：陪你交易，不替你交易。

如果你的桌面也有这样一个小家伙，你最想让它提醒你什么？
